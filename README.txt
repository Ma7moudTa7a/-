تشغيل المشروع (مجاناً 100%):
====================================
1) افتح المجلد في VS Code.
2) للحصول على مفتاح Groq المجاني (بدون فيزا):
   - ادخل على: https://console.groq.com/keys
   - سجّل بحساب جوجل واضغط "Create API Key"
   - انسخ المفتاح الذي يبدأ بـ gsk_
3) ضع المفتاح إما:
   - داخل ملف .env أمام GROQ_API_KEY=
   - أو مباشرة من واجهة الموقع عبر زر "الإعدادات ⚙️"
4) تشغيل السيرفر:
   npm start
   (أو node server.js)
5) افتح المتصفح على:
   http://localhost:3000

====================================
للنشر ومشاركة رابط عام على Render:
1) ارفع المشروع إلى مستودع GitHub خاص أو عام. لا ترفع ملف .env؛ فهو مستبعد من Git.
2) في Render اختر New > Blueprint، ثم اربط مستودع GitHub.
3) سيقرأ Render ملف render.yaml ويطلب منك قيمة GROQ_API_KEY.
4) أضف مفتاح Groq في إعدادات Environment Variables داخل Render، ثم اضغط Deploy.
5) بعد اكتمال النشر، شارك رابط الخدمة الذي ينتهي بـ onrender.com.

تنبيه: إذا وضعت GROQ_API_KEY على الخادم، فكل من يملك الرابط سيستخدم حصة المفتاح نفسه.
لا تشارك المفتاح نفسه مع الآخرين، وراقب الاستخدام من لوحة Groq. ويمكن لكل مستخدم
إدخال مفتاحه الشخصي من زر الإعدادات بدلًا من ضبط مفتاح مشترك على الخادم.

للموبايل، رابط Render يعمل عبر HTTPS، لذلك يمكن استخدام الميكروفون وتثبيت التطبيق:
- التثبيت كتطبيق PWA:
  أندرويد (Chrome): القائمة > Install app
  آيفون (Safari): مشاركة > Add to Home Screen
